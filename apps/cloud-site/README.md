# Сайт Rox Cloud

Четыре страницы без сборки и зависимостей: главная, документация, цены и
состояние. Один общий `styles.css`, системные шрифты, ни одной внешней картинки.

## Как посмотреть

Из корня репозитория:

```bash
python3 -m http.server 8082 -d apps/cloud-site
```

Затем откройте <http://localhost:8082/>. Открывать `index.html` двойным щелчком
не стоит: у страницы с диска нет адреса API, и проверка на `status.html`
честно скажет, что проверять нечего.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Герой, семь продуктов, три шага, `curl` до первой машины, блок «что мы не делаем». |
| `pricing.html` | Модель счёта, формула `стоимость = часы × ставка`, помеченный пример, таблица «что входит». |
| `docs.html` | Быстрый старт, все маршруты из `apps/cloud-api/openapi.yaml`, конверт ошибок, MCP-сервер. |
| `status.html` | Живая проверка `/health` из браузера и ссылки на страницы состояния поставщиков. |
| `styles.css` | Токены `--surface-*`, `--border`, `--accent`, `--text-muted` и вся вёрстка. |

## Ссылки на консоль

Кнопки «Открыть консоль» ведут на `/console/` без имени хоста: предполагается,
что сайт и API отдаёт один процесс и консоль смонтирована по этому пути
(`apps/cloud-console/`). Если сайт поднят отдельно, как в команде выше, ссылка
`/console/` на локальном сервере сайта не существует — это ожидаемо.

## Состояние

`status.html` запрашивает `/health` у того же адреса, с которого открыта
страница. Другой адрес задаётся параметром:

```text
status.html?api=http://localhost:8787
```

Браузер должен видеть этот адрес напрямую; при другом источнике без CORS
страница покажет «API не отвечает» и предложит проверить тем же адресом через
`curl`. Чтобы проверка с чужого источника работала из браузера, API запускают
с `ROX_CORS_ORIGIN=http://localhost:8082` (адрес сайта, без слэша в конце).

## Где менять пример ставки

Ставка платформы — не прайс на сайте, а значение из кабинета. Единственная
цифра-пример живёт в `pricing.html`, в блоке `<div class="example">`, строка
`<p class="math">2 ч × 1,00 $/ч = 2,00 $</p>`. Меняйте её вместе с пометкой
`пример, ставка задаётся в кабинете`, чтобы пример оставался арифметикой, а не
обещанием цены. Больше нигде на сайте долларовых сумм нет.

Настоящая ставка задаётся при запуске API переменной
`ROX_PLATFORM_RATE_CENTS_PER_HOUR` (целые центы за час работы одной машины) и
показывается в кабинете; см. `apps/cloud-api/README.md`.

## Правила текста

- Названия и определения продуктов берутся из
  `packages/ui/src/lib/product-names.ts` дословно: те же семь слов в кабинете,
  документации и счёте.
- Rox не заявляет SOC 2 или HIPAA. Аттестации, если они есть, относятся к
  площадкам поставщиков.
- Каталог не рекламирует возможности, которых нет: сегодня машины запускаются
  на Daytona, ключи Modal и E2B можно сохранить, адаптера у них пока нет.
- Справочник маршрутов повторяет `apps/cloud-api/openapi.yaml`; при изменении
  контракта таблицу в `docs.html` правят вместе с ним.
