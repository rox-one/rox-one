Как читать отказы

По умолчанию проверяется тот же адрес, с которого открыта страница. На локальном стенде, где сайт отдан отдельно от API, укажите адрес явно: status.html?api=http://localhost:8787.

Ответ «API не отвечает» означает, что из этого браузера адрес недоступен: сервис остановлен, адрес другой или сеть закрыла запрос. Это не приговор сервису — проверьте тот же адрес командой curl -sS <адрес>/health.

Состояние поставщиков

Машины работают на площадках поставщиков. Их состояние смотрит панель для сотрудников и страницы самих поставщиков — по одной на каждого:

  • Daytona — официальная страница состояния Daytona.
  • Modal — официальная страница состояния Modal.
  • E2B — официальная страница состояния E2B.
Ссылки ведут на страницы поставщиков: Rox не копирует их состояние и не подставляет свои адреса. Если поставщик недоступен, Rox вернёт provider_error с request_id — назовите его поддержке.

Что считается ответом

  • API отвечает — на /health пришёл ответ 200 с телом {"ok":true}. Время и задержка показаны рядом.
  • API не отвечает — ответа нет за отведённое время, пришёл другой код или браузер закрыл запрос.
  • Страница не проверяет поставщиков, кошелёк и отдельные машины: для этого есть кабинет и журнал.
