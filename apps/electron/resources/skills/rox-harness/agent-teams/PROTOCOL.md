# Agent Teams protocol (Rox)

Staged plan → user approve → `spawn_session` members → dependency tasks → `send_agent_message` coordination → captain summary → archive labels.

Durable Cordis UI / `.agent-teams/` host routes from `@nanmicoder/dsh-agent-teams` are **out of scope** for Rox. Use DSH desktop profile if you need the upstream activity panel.
