# Follow-up Tasks Flow

1. Use `tasks_today` when the user asks what needs attention now.
2. Use `dialogs_list` to gather candidate chats.
3. Use `chat_read` for context when creating or suggesting a task.
4. Use `tasks_suggest` for AI suggestions.
5. Use `tasks_add` for approved or explicit tasks.
6. Use `rules_add` and `rules_run` for recurring follow-up behavior.

Prefer small, specific tasks over broad reminders.
