# Flow

1. Resolve the peer or list recent dialogs.
2. Read the latest messages for context.
3. Ask AI-backed tools for tags, company, and task suggestions.
4. Classify lead quality from explicit intent, budget, urgency, company fit, and requested next step.
5. Persist CRM changes only after the user asks to apply them.
6. Report the lead stage, supporting evidence, and next action.
