# ADR-0025: Пакетный конвейер импорта с прогрессивной отрисовкой

- **ID:** `RX-ADR-0025`
- **Status:** Accepted
- **Date:** 2026-10-13
- **Branch:** `perf/program-setup-20261013`
- **Refs:** эпик #1596, [import-pipelines.md](../../perf/import-pipelines.md), ADR-0024

RFC 2119: MUST / MUST NOT / SHOULD / MAY.

## Context

Все 11 конвейеров импорта идут в главном процессе. Автоимпорт чатов из других агентов включён по умолчанию, стартует через 20 с после запуска, повторяется каждые 15 минут и на каждый новый чат перечитывает тела всех существующих сессий (O(N×S)), переписывает реестр, пересобирает индекс сессий и шлёт отдельное событие; рендерер на каждое событие делает `getSessionMessages` и O(S)-копию атома. Автоимпорт истории браузера синхронно копирует базу History и читает до 50 000 строк каждые 15 минут. Окно выбора чатов для импорта рисует до 100 000 строк без виртуализации, Drive опрашивает весь план каждые 1,5 с.

## Decision

1. **Стадии.** Импорт MUST идти как конвейер: обнаружение → разбор (CPU, пул воркеров ADR-0024) → запись (IO, `limit(n)`) → индекс (пакетно) → уведомление (коалесцированный прогресс не чаще 10 раз в секунду).
2. **Дедупликация по индексу.** Проверка «уже импортировано» MUST опираться на карту источник → сессия, построенную один раз за прогон; тела существующих сессий MUST NOT читаться ради дедупликации.
3. **Пакеты.** Реестр и индекс сессий обновляются один раз на пакет; рендерер получает одно событие на пакет с краткими данными сессий (без последующего `getSessionMessages` на каждую).
4. **Уступчивость.** Между пакетами конвейер MUST уступать циклу событий; прогон отменяем.
5. **Не мешать старту.** Автоматические импорты MUST стартовать только после первой отрисовки и в простое; пользовательские действия имеют приоритет.
6. **Прогрессивная отрисовка.** Списки обнаруженных и импортированных объектов MUST быть виртуализированы и постраничны; первые элементы видны сразу, остальные дозагружаются.
7. **Порядок перевода.** Первым переводится автоимпорт чатов (наибольший эффект), затем импорт истории браузера, затем Drive (опрос → существующие push-события), затем остальные.

## Consequences

- Импорт 150 чатов при 1 000 существующих сессий: ноль чтений тел существующих сессий, не больше 4 записей реестра и 4 пакетов ingest.
- Тесты конвейеров считают операции (чтения, записи, события), а не время.
