# Golden Gate — индекс требований, реализации и проверки

Родитель: [#541](https://github.com/rox-one/rox-one/issues/541). Изменения: [PR #584](https://github.com/rox-one/rox-one/pull/584). База исходной инвентаризации: `22c8b89858f8c41d3f687f13d49a31b55045c146`. Дата: 2026-09-14.

Ветка содержит изменения оболочки, геометрии панелей, навигации, общих примитивов, диагностики и статусов, а также отдельные доработки чата, заметок, задач и встреч. Присланный пользователем снимок ROX разобран как исходное состояние. **Визуальная приёмка результата и проверка Electron/macOS не завершены:** политика доступа блокирует локальный продуктовый URL. Все 25 опубликованных задач остаются открытыми до своих критериев приёмки.

## Что реализуется и что остаётся

| Область | Покрытие на текущей итерации | Остаток |
|---|---|---|
| Токены/типографика/semantic text | Изменены shared/renderer CSS, темы, Markdown и общие controls; мигрированы общие headers/settings/collection primitives. Заголовки покрывают 22/22 settings, общие карточки — 20/22. | Индивидуальный просмотр всех экранов, contrast и rich-content visual QA. |
| Rail/context navigation | Постоянная ActivityRail, контекстный LeftSidebar и компактное меню сервисов/панелей; повторный выбор фокусирует существующую панель. Свёрнутые начальные группы, скрытие нулевых счётчиков, компактные профиль и подсказка памяти. | Продуктовый keyboard/visual flow всех сервисов; настройка отдельных сложных navigator. |
| Панели 2×2/3×2 | Геометрия и размеры по пространствам, изменение по обеим осям, направленный переход к соседней панели и клавиатурные разделители. В единственном пустом каталоге не дублируются detail и строка вкладок. | Полный 4/6-panel mixed-surface QA, state/restart и native focus/visibility acceptance; измерения времени кадра. |
| Диагностика | Есть collector/IPC/preload/types и UI чипа; narrow read-only контракт. | Реальные macOS/remote metric samples и native visibility; доказательство всех poll lifecycle случаев. |
| Header status / suggestions | Одна полоса статуса, приоритеты, дедупликация и отсчёт только оставшегося времени чтения; пауза при фокусе, наведении, меню и скрытом окне. Действия подсказок проверяют актуальный контекст. | Screen reader/visual QA, испытание релевантности E06; не все производители событий перенесены в полосу. |
| Чат и ввод | Компактная панель ввода, раскрываемые дополнительные инструменты, высота по фактическому содержимому; автопрокрутка ограничена своим чатом. Диктовка дописывает текущий черновик и отклоняет устаревшие ответы. | Реальная запись звука, IME, длинные разрешения/модели и потоковый ответ в узких панелях. |
| Заметки | Бюджет ширины для боковых областей, инструменты в меню/временных панелях, сохранение редактора при смене представления. Исправлены поздние чтения, подтверждение старого сохранения и фокус комментариев; черновики комментариев разделены по пространству/заметке. | Реальный rich-editor цикл и визуальная приёмка всех представлений; черновики комментариев не обещают восстановление после перезапуска приложения. |
| Задачи и встречи | Помимо direct links, доработаны компактные каталог/карточка, формы и раскрываемые подробности. Сохраняются несохранённые поля; контролируются повторные действия и поздние ответы встреч из другого пространства. | Приёмка на реальном сервере, запись встреч, внешние интеграции; общая миграция проектов ещё не закрыта. |
| Все 22 settings и коллекции | Общие primitives покрывают часть стиля; поля наследуют подписи/описания, ошибки связаны с полями, меню и фильтры получили дополнительные клавиатурные и семантические проверки. | Индивидуальные тела 22 страниц и все состояния требуют приёмки; общие primitives не закрывают GG-019…023 автоматически. |
| Прочие сервисы | Источники, навыки, память, Knowledge, автоматизации, страницы, расширения и onboarding включены в инвентаризацию и получают часть общих изменений. | Их полная индивидуальная переработка и приёмка из GG-008…024 остаются открыты; наследование темы не считается завершением. |
| Inspector / native surfaces / terminal/cloud-run | Инспектор без адресата не занимает пустую широкую колонку; сохранены явные предпочтения. Native bounds и владельцы согласованы с видимостью панелей. | Native-поверхность отображается только при фокусе и полной видимости; одновременная композиция нескольких частично обрезанных native views не реализована. Electron/macOS lifecycle остаётся открытым. |
| Visual/native release gate | [GG-025 / #578](https://github.com/rox-one/rox-one/issues/578) открыт. | Нужен разрешённый продуктовый стенд; обход текущей browser policy запрещён. |
