## Правила пустого состояния

1. Нельзя одновременно отводить постоянную площадь нескольким пустым представлениям одного сервиса.
2. Основное действие первого запуска — создание сессии. Настройка памяти и дополнительные инструменты раскрываются по запросу.
3. «Нет данных», «ничего не найдено» и «ошибка загрузки» остаются разными состояниями. Фильтр не должен приводить к сообщению, будто пользователь ещё ничего не создавал.
4. Расширение списка не меняет сохранённую ширину навигатора, геометрию других панелей и существующие маршруты.
5. Скрывшийся блок становится недоступным для Tab и native bounds, при этом его устойчивый владелец и редактор сохраняются.
6. Чтение настроек ничего не записывает. Переключение пространства не должно сохранять в новое пространство состояние предыдущего.
