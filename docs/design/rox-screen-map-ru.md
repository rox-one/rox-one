# Карта экранов Rox (2026-10-08, целевое состояние батча оболочки)

Для комментариев по UI. По каждому экрану: что где, что сгруппировано, что открывается
в новой панели, что заменяет текущий центр. Источник: инвентарь по коду рабочего дерева
(`agent://E1ScreenInventory`) + решения батча `docs/plans/2026-10-08-rox-user-batch.md`.

## Оболочка (зоны)

| Зона | Содержимое (целевое) |
|------|----------------------|
| Левый рейл | Только 7 режимов, одни серым цветом (как «+»/«добавить рабочее пространство»): Главная, Сессии, Встречи, Задачи, Заметки, Лента, Входящие. Низ: `⚙` (настройки) и «Скрыть/показать боковую панель» в одном ряду; плашка пользователя — ниже, во всю ширину. Прежние назначения (Проекты, Страницы, Память, Источники, Навыки, Автоматизации, Подключения, Настройки) — в свёрнутом «Разделы приложения» внутри боковой панели |
| Центр | Стек панелей (`panel-stack`): фокусная панель + панели рядом (делят ширину). Число панелей не ограничено |
| Правый рейл (действия) | Сверху вниз: `+` (новая сессия), новая задача, новое событие, новая заметка, браузер. Внизу: pin (появляется только в hover-состоянии), «Скрыть/показать» (ChevronsRight) выше, затем отступ и терминал — самый нижний элемент (TZ: «терминал — в самой нижней кнопочке… выше — кнопочка вскрытия и раскрытия сайдбара»). Кнопки «Инфо» нет — секция `info` не рендерится нигде. На home/экранах без панелей рейл не монтируется (`[data-inspector]` нет; при свёрнутом виде — 28px-полоса `inspector.expand`) |
| Инспектор (правая панель) | Закрыт по умолчанию на всех экранах после запуска. Hover по левой/правой кромке разворачивает скрытую панель (вне SE-профиля тоже). Секции сессии: files / git / browser / context |
| Терминал | Панель под ПЕРВОЙ колонкой, делит высоту пополам (50%); движок — псевдо-TTY через `shell.EXEC` + ANSI |
| Пилюли режимов | `ModeBar` в титлбаре не тронут этим батчем (дублирует состав рейла — вопрос к пользователю в чате) |

## Правило «панель или замена»

- **Клик по элементу списка на любом экране = замена центра** (`navigate(routes.view.<режим>(id))`), пропорции стека сохраняются.
- **Новая панель рядом** появляется только там, где это явно предусмотрено:
  - правый рейл действий: задача / событие / заметка / браузер (`pushPanelAtom` с `afterIndex` — панель встаёт справа от фокусной); `+` — новая сессия (навигация);
  - ⌘-клик по сессии в списке чата, «Открыть в новой панели» из меню сессии, «Новый чат в панели» (`TopBar`);
  - из чата: навыки / источники / настройки ИИ / аккаунты (`navigate(..., {newPanel:true})`).
- Внутриэкранные переходы (задача из встречи, сессия из задачи, источник из ленты) — обычный `navigate`: заменяет центр.

## Что сгруппировано

- Левый рейл: 7 режимов; всё остальное — «Разделы приложения» (свёрнуто).
- Правый рейл: 5 «создать/открыть» сверху; внизу — pin / терминал / скрытие.
- Сессии: «текущее представление / другие / непрочитанные / прочитанные».
- Задачи: области и проекты в sidebar; в шапке — быстрый ввод, сортировка, корзина, magic-plus.
- Встречи: план-форма + импорт/запись — в шапке списка; деталь — табы.
- Лента: фильтры источника/тега/дня — в шапке списка; действия — в reader.
