# Озвучивание через edge-tts

Действие **«Ещё» → «Слушать»** у сообщения использует движок из **Настройки → Ввод → Голос — Общие → Текст в речь**. При выборе **Edge TTS** ROX получает MP3 от онлайн-сервиса Microsoft Edge и воспроизводит его в клиенте. Ключ API и установленный браузер Edge не требуются.

Для синтеза нужен интернет. Текст сообщения отправляется в Microsoft; записи микрофона не отправляются. `uploaded: false` в голосовом RPC означает отсутствие загрузки исходного аудио, а `textSent: true` отмечает отправку текста для успешного синтеза.

## Запуск

ROX сначала ищет установленный `edge-tts` через резолвер toolchain/PATH. Если команды нет, использует `CRAFT_UV` (bundled uv в Electron) или `uv` из toolchain/PATH:

```sh
uv tool run --from edge-tts==7.2.8 edge-tts --version
```

При первом запуске uv скачивает Python-зависимости в свой изолированный кеш. Для предварительной установки CLI:

```sh
uv tool install edge-tts==7.2.8
edge-tts --version
```

При нестандартном расположении можно задать абсолютный путь через `CRAFT_EDGE_TTS=/path/to/edge-tts` перед запуском ROX. Это путь к исполняемому файлу, без дополнительных аргументов и shell-команд.

Язык из настроек распознавания определяет голос: `ru` → `ru-RU-SvetlanaNeural`, `en` → `en-US-AriaNeural`. При `auto` кириллица в тексте выбирает русский голос, остальной текст — английский.

## Поведение и ограничения

- Текст передаётся CLI через stdin (`--file -`), без shell и без текста в аргументах процесса.
- Синтез ограничен 20 секундами и 20 000 символами; размер MP3 ограничен 16 MiB.
- MP3 передаётся по RPC как `audioBase64` с `mimeType: audio/mpeg` и `playback: audio`. Аудио играет на устройстве клиента, в том числе при подключении к удалённому серверу.
- Временная папка удаляется после успеха, ошибки или отмены; браузерный Blob URL освобождается после завершения и остановки.
- Во время озвучивания действие «Слушать» меняется на «Стоп»: оно останавливает воспроизведение и отменяет незавершённый синтез. Выбор другого сообщения отменяет предыдущий запрос.
- При недоступности edge-tts или сети применяется существующий резерв: macOS `say`, затем Web Speech API клиента. Fish Speech по-прежнему использует этот резерв.
