## Производительность и ограничения

`projection-benchmark.json` измеряет только core projection. Его p95 нельзя выдавать за renderer latency. Browser measurement начинается непосредственно перед canonical ingress; MutationObserver подтверждает видимый текст того же node, следующий animation frame фиксирует paint opportunity. Транспортная/SSE задержка в этот бюджет не входит. Pan frame timestamps снимаются во время реальных pointer moves по production ReactFlow.

Старые raw pan failures50/100ms и traced event267/405ms сохранены для аудита. Playwright trace snapshotter и recorder были исключены из performance budget после CPU profile; функциональные видео пишутся отдельно. Final untraced/unrecorded public-Fit gate показывает200actualvisible cards: event14.1ms, dense completion status/icon29.5ms, pan16.8ms. Raw старыеfailures33.4/50/100ms сохранены. Chromium finalJSHeapUsed36,132,156bytes/total77,885,440bytes; pan cumulative-counter deltasTask4.174741s, Script.822312s, Layout.475287s, RecalcStyle.170661s. Hardware AMD EPYC9V74,9logicalCPU/8cgroupquota,8GiBmemory limit, Linux6.18.44; raw before/after counters и elapsed находятся в JSON. Эти счётчики не CPU percentage. Финальный report сохраняет отсутствие macOS/Windows installed-app smoke и paid/live-provider checks. Local Native Unix lock EPERM не обходился; hosted Ubuntu native loop succeeded with native locks, integrity guards, model readback и permission responses intact.

## Воспроизведение

1. Установить project dependencies закреплённым Bun согласно lockfile.
2. Установить browser из repo Playwright 1.49.1 (`node node_modules/@playwright/test/cli.js install chromium`).
3. Запустить приведённую Playwright команду. Она создаёт только временную test session, production renderer bundle под node_modules cache и loopback server.
4. `browser-results.json` и версионные `browser-artifacts/<ROX_RUNTIME_EVIDENCE_RUN>/` содержат raw results, screenshots, WebM и failure traces. Readable final stream сохранён координатором также в `docs/evidence/runtime-map/media/`. Они не являются persisted credentials или user data.

Полная приёмка R01–R30 не заявляется, пока строки BLOCKED/FAIL/PARTIAL не закрыты координатором проверкой соответствующего класса.
