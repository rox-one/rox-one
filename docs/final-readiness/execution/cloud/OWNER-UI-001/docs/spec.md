# UI-001: интегрированный ремонт

Владелец: OWNER-UI-001, один писатель. Исходная ревизия: `76228cc33e44518e5fab5e59f5c754f4051d1e8c`. Пользователь расширил исходную границу до полного ремонта связанных исходников, GitHub-записей и merge main. Новые функции актуального main сохраняются.

Неизвестная либо повреждённая ссылка должна сохранять свой адрес и показывать недоступную поверхность. Явная сессия не заменяется первым доступным чатом после загрузки метаданных или удаления. Каждая панель, включая фоновую, проверяет принадлежность сессии workspace до монтирования ChatPage; без метаданных запрос не начинается, remote alias поддерживается. Отказ или удалённый workspace в history освобождает suppression через фактический результат переключения App. Структурированная запись панелей сохраняет запятые, двоеточия и экранирование в адресах; старые ratio-ссылки читаются без переписывания сущностей. Отложенная навигация сохраняет адрес, параметры и опции. Переход до завершения кадра восстановления создаёт свой шаг history. Каталог навыков разрешается в той же рабочей папке при начальном и живом обновлении. Обновление не уничтожает черновик; подтверждённое удаление показывает конкретное отсутствие.

Геометрия восстанавливается по workspace до сохранения старого состояния. Размеры ограничены допустимыми диапазонами; отказ хранилища и старые межоконные события не ломают текущую панель. Новая split-панель получает положительную долю ширины с сохранением пропорций соседей. Старые нулевые/единичные доли распознаются как метаданные layout и восстанавливаются без изменения адреса сущности. Существующие recovery/retry/error-boundary/lazy-import возможности main сохраняются.

Четыре исходных поля acceptance каждого задания сохранены дословно в result.json. fullDoDClosed остаётся false до наблюдения исходной Windows 10/11, native macOS и actual hosted матрицы с каноническими backend receipts. Компонентные и Chromium стенды имеют явно обозначенную границу.
