# Runtime Map: фактическое происхождение и сохранённые результаты

Выборочный перенос 14 путей из замороженного #1444 `c2e8f07b5cb8a1b1659781e1fe4dd4d0f0207727`. Коллектор и DTO уже доставлены отдельным #1485; текущие интерфейсы авторизации сохранены. Этот кандидат дополняет фактические отправители и исполнитель, исходные ветки остаются.

SessionManager сохраняет третий аргумент `suppliedExecution`; происхождение наблюдения передаётся отдельным четвёртым аргументом. Запись после ожидания требует прежнего владельца и действующей нативной области. Создание дочерней сессии сохраняет `assertCurrent`/`bind` до отправки. Канал, расписание, автоматизация, импорт Cloud Run и генератор задач передают собственное происхождение, которое не даёт прав исполнения.

TaskRunner захватывает сохранённые output/ref/message до постановки пассивного наблюдения в очередь. Реальный повтор запроса verdict подтверждает, что последующая перезапись канонического файла не меняет предыдущую версию наблюдения. Нативное чтение скрывает host/task/header/verdict содержимое и разрешает исходный пользовательский запрос только по наблюдённому корневому вводу. Нативный SEND удаляет чужую producer metadata на реальной подписанной RPC-границе.

Старый ответ или разрешение host-frame не выполняется и не отвечает за новый запрос с тем же ID. Отмена транспорта отмечает неизвестность завершения физического процесса. Наблюдатель читает уже открытый дескриптор своего журнала при любом уведомлении приватного каталога: имя события не выбирает путь. Это исправляет реально измеренное объединённое уведомление с именем файла расширения, которое прежний фильтр игнорировал.

Предыдущая SDK-итерация имела 66 наблюдений и сохранена отдельно; результаты итераций не складываются. Два новых host-frame теста проверяют реальный метод с контролируемой идентичностью child, а не запущенный нативный процесс. Они дополнены реальными процессными сценариями отмены, нормальной MCP-цепочкой и модельной границей учётной записи.

Полная история ошибок сохранена. Первая собственная фикстура ошибочно блокировала очередь до dispatch; исправленная проверка использует реальный verdict re-ask. Промежуточная lease-проверка была поставлена после удаления map entry и подавляла правильный ответ; отрицательные и положительные проверки поймали это до публикации. Ошибочное ожидание возвращаемого значения от `respondToPermission` исправлено по фактическому void-контракту. Два промежуточных объединённых прогона не были зелёными; исходные журналы, отдельные повторения и конечный зелёный прогон сохранены.

Неизменённый текущий `main` прошёл burst-тест в одной итерации; это не объявляется универсальной ошибкой main или доказательством нагрузки хоста. Зафиксированная ошибка кандидата содержала реальное уведомление `rox-runtime-observer.js`, ноль decoder errors и 32 непрочитанных кадра; исправление не увеличивает трёхсекундный срок и не вызывает ручной drain в тесте.

Standalone gateway typecheck остаётся не зелёным из-за других старых enum-фикстур, export/composite-конфигурации. `gateway-scoped.tsconfig.json` явно проверяет фактический entry и изменённый button-test с текущими строгими настройками/aliases Server-core; это не blanket pass всего gateway-пакета.

Это локальная ограниченная квалификация. Она не доказывает установленное приложение, живого/платного провайдера, точную HTTP-сериализацию или токенизацию, Windows console либо full native/cloud/release DoD. Parent выполняет review и слияние отдельно. `verification.json` содержит ревизии, blob/SHA256, команды/границы и manifest архивированных журналов. Все исходные ветки сохранены.
