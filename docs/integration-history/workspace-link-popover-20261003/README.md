Форма быстрых ссылок workspace вынесена из узкой боковой панели в доступный Radix Popover. Реальные поля шире200px, форма помещается в320px экран, Enter сохраняет через существующий workspace store, Escape/Cancel сохраняют несохранённый черновик, смена workspace закрывает форму без чужой записи.

Источник: PR#1447 e004a44; перенос адаптирован к текущему @rox/ui и TourTarget. Девять проверок реального компонента/Select/Popover/CSS проходят, старая версия воспроизводит поле25px. Полный Electron typecheck проходит. Проверки используют headlessChrome с контролируемыми backend/translation/navigation seams; установленный macOS/Windows пакет и полная локализация визуально не проверены.
