## Findings that prevent false parity

Macro Task recurrence not established; ROX recurrence preserved. CRM inbound unknown company creation is target enhancement. CRM Company search is PostgreSQL opt-in, Contacts/discussion content coverage incomplete. Calendar working-hour/availability behavior is local prefs/busy display, not general remote availability service. Calls without transcript are not indexed in current pipeline; recording/STT/summary optional and processing errors can leave partial archive. Canvas/code are not automatically CRDT. Memory is per-user profile refresh, not unified fact graph. Root/license package conflict blocks literal web copy (18).
