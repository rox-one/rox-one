# Macro → ROX central mapping matrix

Baseline и статусы — README; source evidence indexed by id in `plans/macro-integration/evidence-*.json`. Каждая строка ниже = отдельный capability; полный machine-readable вариант включая files/newFiles/port layer/license/links — capabilities.json. Target approach означает architectural treatment; PORT_DOMAIN не лицензия на буквальное копирование.

Frontend column показывает **surface entry point**, не единственного action owner. Exact repository/SHA/path/symbol/ranges и observed limitations находятся в capabilities.json::evidenceRefs. Code-level change contracts — ::codeLevelChanges и work-packages.json; общие search/ACL/MCP поля inventory обозначают audited subsystem integration, entity eligibility отличается и проверяется в 14–16.
