## 2. План волн (параллельные сессии)

### W1. Почта — реальная отправка/приём (критический путь)
Цель: любой пользователь получает `handle@rox.one`, может отправлять на внешние адреса и получать от них.
Архитектура (рекомендованная):
1. Сервер Stalwart на testct (docker compose): домен `rox.one`, JMAP 8480 (публично через cloudflared-туннель как `mail.rox.one`), SMTP 2525 (только localhost).
2. Исходящие: Stalwart relay → Resend SMTP (smtp.resend.com, ключ) — домен rox.one верифицируется в Resend через CF DNS (DKIM/SPF).
3. Входящие: CF Email Routing — per-адресные правила `handle@rox.one → Worker` (catch-all остаётся прежним, чтобы не ломать живую пересылку) → Worker `rox-email-inbound` (обновить код) → HMAC POST на `mailhook.rox.one` (тот же tunnel) → ingest-сервис на testct → SMTP 127.0.0.1:2525 → Stalwart → JMAP → приложение.
4. Провisионинг: при регистрации/входе сервис создаёт ящик `handle@rox.one` в Stalwart (admin API) + app-password, отдаёт клиенту.
5. Десктоп: server URL переключается на `https://mail.rox.one`, снимается блокировка внешних получателей, включается реальная отправка (JMAP EmailSubmission → Stalwart → Resend).
Критерии: письмо с внешнего ящика (gmail) доходит в приложение; письмо из приложения доходит на gmail; bounce/ошибка видны в UI.

### W2. Аудио в чате → мгновенная транскрибация + замена вложения
Цель (дословно): «если я дропнул ЛЮБОЙ аудиофайл в чат с агентом — он немедленно должен начать транскрибировать и вместо вложения-аудио прикрепить только транскрипцию».
- Триггер: drop/paste/attach аудиофайла в чат.
- Мгновенный старт транскрибации (Deepgram nova-3 через серверный прокси; локальный whisper как fallback), прогресс в карточке вложения.
- По готовности: вложение-аудио заменяется на текстовый блок транскрипта (с разделами/пунктуацией; исходный файл остаётся доступен «показать аудио»).
- Ключ Deepgram НЕ встраивается в клиент: прокси на сервере Rox.

### W3. Таблетки (пилюли) на всех поверхностях
- Включить ModeBar на всех поверхностях (единая точка `AppShell.tsx:3004` + `TopBar.tsx:182`).
- Рестайл: серые монохромные иконки 14–15 px, высота пилюли 28 px, компактные подписи, glass-подложка (backdrop-blur, тонкая обводка), активная — мягкая подсветка; hover — «хочется нажать».
- Unified-поверхности и extra-screens — тоже.

### W4. Кнопки — редизайн в glass-стиле

- Единый компонент-пресет (glass button) + применение по всем местам.

### W5. Баланс и аккаунт — всегда синхронизировано
