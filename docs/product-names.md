# Названия продуктов Rox Cloud

Один словарь для кабинета, документации и счёта. Клиент видит эти семь слов везде; внутренние имена в коде и API не меняются.

| Продукт | Что это | Единица |
|---|---|---|
| Песочницы | Изолированная машина на минуты или часы: выполнить код, запустить агента, собрать проект. | час ядра, час гигабайта памяти |
| Рабочие столы | Машина с экраном, мышью и клавиатурой для Linux, Windows или macOS. | час ядра |
| Видеокарты | Почасовая аренда видеокарты для обучения, вывода моделей и агентов. | час видеокарты |
| Задания | Пакетная работа: прогнать много задач параллельно и забрать результат. | час ядра, час видеокарты |
| Службы | Постоянный адрес, который отвечает по сети и сам масштабируется. | час ядра |
| Диски | Постоянное хранилище, общее для нескольких машин. | гигабайт в месяц |
| Шаблоны | Образ машины из файла сборки: собрали один раз, запускаете тысячи. | минута сборки |

Источник слов — `packages/ui/src/lib/product-names.ts`. Проверка: `bun test packages/ui/src/__tests__/product-names.test.ts`.

Правила: слово «облачная ВМ» не используется, вместо него «Песочницы» или «Рабочие столы»; слово «прогон» остаётся только для внутренней работы агента и не попадает в счёт; суммы пишутся с двумя знаками после запятой и знаком доллара после числа, время — по UTC.
