## 3. Обязательные негативные и контрольные случаи

1. **Дубликат-контроль.** Для каждой U-строки — ровно один первичный владелец; попытка создать новый тикет
   под scope `#380/#381/#382/#385/#387/#389/#541` должна приводить к переиспользованию, а не к новому телу.
2. **Детский счёт #541.** Ровно 25 детей (`#553` + `#555…#578`); `#554` отсутствует и не выводится;
   результат 24/26 блокирует приёмку.
3. **U25-негатив.** Конфликт записей остаётся неразрешённым; никакое изменение shell/Map-поведения или
   дефолта требования не авторизовано.
4. **Закрытия не по догадке.** `#356`/`#333` остаются CLOSED и не поднимаются автоматически;
   `#385` E3 не помечается принятым из-за merge PR #991; `#387` не снимается с hold.
5. **Граф-негатив.** Дубликат ID, цикл или непустые `dependsOn` у `PROGRAM-01` = fail.
6. **Сохранность чужой работы.** Существующие рабочие копии и overlay не очищаются, не сбрасываются и не
   переписываются; baseline пользователя сохраняется при интеграции.
7. **Публичная безопасность.** Нет сырых промптов, приватных абсолютных путей, секретов, cookies и
   персональных данных; приватные входы не изменены.
8. **Несужаемость DoD.** Финальная матрица принимается отдельно на Linux/cloud, Mac native, Windows native
   и iOS-слоте; отсутствие среды помечается BLOCKED/UNVERIFIED, а не PASS.
