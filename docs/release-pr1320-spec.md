## Приёмка

1. У каждого обнаруженного незавершённого направления есть источник, фактическое состояние, владелец и следующий исполнимый шаг.
2. Активные сессии определяются по живому процессу, экрану и артефактам. Метаданные `running`/`idle` сами по себе не подтверждают выполнение.
3. Для Codex Cloud проверены сохранённая среда, привязка репозитория и реальное исполнение задачи; публикация среды, выполнение и успешная проверка фиксируются отдельно.
4. Готовая, но недоставленная работа получает проверку и удалённый артефакт. Непроверенные функции и локальные HTML-демонстрации не объявляются реализацией серверного продукта.
5. Исправления проходят целевые тесты и независимую проверку. Доказательства связываются с точным commit и средой.
6. Незавершённые крупные программы сохраняют существующих владельцев и граф зависимостей; новые исполнители не пишут поверх активных worktree.
