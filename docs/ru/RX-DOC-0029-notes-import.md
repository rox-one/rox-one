# ROX Notes: канонический корень, согласованный импорт и граница форка

- **Статус:** Конспект. Оригиналы сохранены целиком в `docs/upstream/notes-import/` (английский, 971 + 579 строк).
- **Дата оригинала:** 2026-08-10 · Продакт-оунер утвердил дизайн для планирования реализации.
- **Связь:** RX-TSK-0411 (UI импорта Notes) — реализация по этому дизайну.

## Контекст

ROX нужна одна принадлежащая пользователю, прозрачная файловая иерархия: канонический воркспейс `~/ROX/Notes/`, организация PARA (Projects/Areas/Resources/Archive) плюс Inbox, Daily Notes и категоризированные Imports. Текущее приложение выводит глобальное состояние из `CRAFT_CONFIG_DIR || ~/.craft-agent` при загрузке модуля (`packages/shared/src/config/paths.ts`), дефолтные воркспейсы и Notes наследуют этот корень, а RPC Notes падают обратно на `~/.craft-agent/workspaces/{id}/notes`. Перенос только одного пути даст расщеплённое состояние и неверные права записи.

Существующая миграция локальных Notes (`knowledge/notes-migration.ts`) имеет ограниченный обход, чекпоинты, хэши и атомарную запись — но generic local Sources небезопасны как модель импорта: произвольный локальный путь попадает в индекс и контекст агента, а канал `knowledge:migrateNotes` remote-eligible несмотря на приём локального пути.

Продуктовое направление — AGPL-совместимый форк ROX Notes со скрытым локальным движком и нативным UI. Решение G2 остаётся OPEN, пороги G1 — TBD; дизайн определяет техническую границу и релизные доказательства, но **не** авторизует дистрибуцию движка сегодня.

## Функциональные требования (FR-1…FR-11)

| FR | Суть |
|----|------|
| FR-1 | Канонический принадлежащий корень `~/ROX` на macOS |
| FR-2 | Видимая иерархия Notes (PARA + Inbox + Daily + Imports) |
| FR-3 | Граница первичного обнаружения (first-run discovery) |
| FR-4 | Согласие (consent) и провенанс per-source |
| FR-5 | Поведение связанных источников (linked-source) |
| FR-6 | Материализованные импорты (копии, не symlinks) |
| FR-7 | Индексация и ретривал агентом только согласированного |
| FR-8 | Локальная граница ROX Notes engine |
| FR-9 | AGPL-совместимый релиз и update-gate |
| FR-10 | Legacy-миграция существующих Notes |
| FR-11 | Продуктовая терминология и платформенная граница |

Ключевое решение: **без raw OS symlinks** — импорты материализуются копиями с провенансом; согласие фиксируется per-source до индексации.

## План реализации (из plan-документа)

План разбивает внедрение на фазы с гейтами соответствия дизайну; детали фаз — в `docs/upstream/notes-import/2026-08-10-rox-notes-root-imports-plan.md`. Для TSK-0411 существенно: UI импорта строится поверх consent/provenance-модели FR-4 и материализации FR-6, без прямого доступа к произвольным путям.
