## 1. Цель

Привести рабочую среду ROX к одному набору правил: одни вкладки, одна пилюля востребованных панелей, полная клавиатура (включая капслок → «Пульт»), один канон иконок и размеров, названные экраны и предсказуемая скорость на больших объёмах данных.

Наблюдаемый результат цикла:

1. Каждая поверхность пользуется одной и той же системой вкладок с одинаковыми размерами, иконками и клавиатурой.
2. Пилюля в обрамлении вызывает самые востребованные панели и подстраивается под реальное использование.
3. Капслок открывает «Пульт»; полная клавиатурная навигация работает в пилюле, вкладках, канбане и браузерных вкладках.
4. Новые экраны («Пульт», «Активность», «Библиотека», «Состояние») и слияния (Лента ← Входящие + Уведомления; Календарь ← Встречи; Команда ← Контакты) сосуществуют с уже отгруженными экранами без дублей.
5. Большие объёмы (заметки, закладки, пароли, сессии) рендерятся в рамках бюджетов, доказанных числами.

Не-цели цикла: переименование и перегруппировка существующих экранов целиком (вариант C — отдельный цикл после отгрузки); смена архитектуры ядра; новые нативные зависимости.

## 2. Термины

По `CONTEXT.md`: **панель** и **вкладка** — разные понятия; **рабочая поверхность** — область содержимого; **обрамление** — верхние и боковые области.

- **Пилюля** — компонент обрамления, вызывающий панели/экраны.
- **Пульт** — командная поверхность (поиск, действия, переходы), открывается капслоком (в приложении) и ⌘K.
- **Сцена** — сохранённая раскладка панелей.

## 5. Целевая архитектура изменений

### 5.1 Пилюля v3 (D1)

- Единый компонент пилюли с режимами: «панели» (элементы-переключатели) и служебные элементы (закрепить/исключить).
- Источник состава: `freq` (счётчик активаций по панели, локально) + явные закрепления; Сцена задаёт состав принудительно.
- Служебные действия: закрепить, исключить, «все панели…» (открывает Пульт), сохранить как Сцену.
- Клавиатура: roving по элементам (расширение существующего `mode-pill-keyboard.ts`), Home/End, Enter/Space.
- Геометрия: размер контейнера и глифа — из токенов (никаких 19px-коробок и литеральных штрихов).

### 5.2 Единая система вкладок (D2)

- База `SurfaceTabs` получает профили: `closable`, `density` (compact/full), `leadingIcon`, `badge`, `overflow`.
- Конфигурации: сегменты представления (без закрытия), браузерные вкладки (закрытие, меню), вкладки поверхностей (закрытие, меню, чипы браузера — по ADR-0001).
- Клавиатура и ARIA: `role=tablist/tab`, `aria-selected`, roving tabindex, Arrow/Home/End, Enter/Space, Delete/Backspace, средняя кнопка мыши, видимый фокус.
- Единая анатомия: высота, глиф, закрытие — из токенов; один словарь глифов.

### 5.3 Пульт и капслок (D3)

- «Пульт» — единая командная поверхность: переходы (экраны/панели/сессии/заметки), действия (из `actions/definitions.ts`), поиск. База — `cmdk` (уже в зависимостях).
- Триггеры: капслок (в фокусе окна) и ⌘K; поведение одинаковое.
- Документация: «системный капслок» — ремап ОС (Hyper), вне приложения.

### 5.4 Клавиатурная полнота (D3, D2)

- Канбан: обход сетки стрелками, Home/End, активация, перенос фокуса между колонками.
- Вкладки: см. 5.2. Пилюля: см. 5.1.
- Один примитив `Kbd` для всех подсказок.

### 5.5 Канон размеров и глифов (D6)

Таблица «роль → токен» фиксируется в `packages/ui` и применяется миграцией; ESLint-правило включается с baseline (ратчет: новые нарушения — красные, старые — в списке). Единственный словарь «сущность → значок» — один модуль-справочник, из него берут пилюля, рейл, вкладки и списки.

### 5.6 Экраны (D4)

- «Активность»: аналитика сессий (теплокарта, тренды, топ-источники).
- «Библиотека»: один экран-каталог: навыки, источники, MCP/инструменты, подключения, интеграции — секции + поиск.
- «Состояние»: сервисы, провайдеры, MCP, синхронизации, очереди, дрейф источников — тихий экран «всё работает».
- Слияния: Лента ← Входящие + Уведомления; Календарь ← Встречи; Команда ← Контакты.
- «Сейф» — существующие «Секреты», принять; браузерные пароли/закладки — импорт в существующие дома, без новых дублей.

### 5.7 Перф (D7)

- Виртуализация списков там, где бывают большие объёмы (сессии, заметки, закладки, пароли).
- Бюджеты рендера/загрузки расширяются на реальные объёмы (не синтетика), фиксируются числа.

### 5.8 Сцены (D8)

- Сохранить текущий набор панелей как Сцену, вызвать из пилюли/Пульта; Сцена — приоритетный источник состава пилюли.

## 6. Приёмка

- Функциональные сценарии (наблюдаемые): капслок→Пульт→переход; закрытие вкладки средней кнопкой и Delete; roving в пилюле, вкладках, канбане; смена состава пилюли после использования панелей; вызов Сцены; слияния (Лента с уведомлениями, Календарь с встречами, Команда с контактами).
- Визуальная: скриншоты изменённых поверхностей; отсутствие регрессий размеров (сравнение до/после).
- Перф: числа на фикстурах больших объёмов (заметки/закладки/пароли/сессии) в рамках бюджетов.
- Платформы: матрица macOS + Windows + Linux + WebUI (в этом окружении выполнимо macOS и WebUI headless; Windows/Linux — через имеющиеся CI-лейны, иначе — явная граница).
- Гейты: `bun run lint`, `bun run typecheck:all` (затронутые воркспейсы), целевые тесты, i18n-паритет.
