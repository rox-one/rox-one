1. Security settings = local credential vault + Infisical-for-Rox + remote TLS + permission modes. Not a new IdP.
2. “Account & security” must not ask for a random email/token as if that were a working login.
3. Browser *profile discovery* at install without a consent prompt is a product call. Importing cookies/passwords still needs OS keychain / explicit persist.
4. Question: is Security a settings page for vault + TLS + permissions, or a full account-auth product?
