The thesis
Rox sells two transitions: an idea becomes a working cloud machine, and the work stays in one durable desktop workspace.
The org exists to make those transitions repeatable. Every division has one outcome, one shared contract and one named consumer.
Idea → machineCatalog, price, key, sandbox, terminal, invoice.
Work → workspaceSessions, knowledge, documents, tools, memory.
